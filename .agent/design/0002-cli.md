# 0002 - CLI

`tool/` holds the standalone demonstration runner. It is not compiled into
`libshell89.a`, is not scanned by `green` (whose project roots are `src`), and
uses only the public `shell89.h` API.

## Command line

```text
shell89 -c <script>
shell89 <file>
shell89 -
shell89
shell89 -h | --help
```

With no arguments or with `-`, the script is read from stdin to EOF. That
script source consumes stdin, so the first stage receives `stdin_fd = -1`. With
`-c` or a file, the script is loaded before execution and stage stdin is the
process stdin descriptor. A source containing a NUL byte is rejected because
the public API takes a NUL-terminated string.

## Exit status

| status | meaning |
| --- | --- |
| shell status | result of the last executed pipeline |
| 1 | CLI runtime failure or `shell89_run()` library error |
| 2 | CLI usage error or script over `SHELL89_MAX_SOURCE` |

The shell already produces 2 for syntax/argument errors, 127 for unknown
commands, and 1 for callback failures. Diagnostics go to stderr.

## Demo vocabulary

| command | options |
| --- | --- |
| `text echo` | `--text` string, required |
| `text upper` | none |
| `text lower` | none |
| `text count` | `--lines` flag |
| `text grep` | `--pattern` string required, `--ignore-case` flag |
| `text head` | `--lines` string required |
| `text skip` | `--lines` string required |
| `files read` | `--path` string, required |
| `files write` | `--path` string required, `--append` flag |

The vocabulary is deliberately small and native. The CLI registers no external
executables, so there is no implicit `PATH` lookup, shell escape, or process
registration policy. Hosts that need real capabilities embed the library and
register their own commands.

`files read` and `files write` are binary-safe and stream in bounded chunks.
`text count --lines` counts LF bytes and adds one when the stream is non-empty
and does not end in LF. `text upper` and `text lower` fold ASCII only.

Line-oriented commands are documented in `0003-line-commands.md`. They use a
64 KiB line cap, preserve final-newline state, and are literal rather than
regex-based.

## Modules

- `tool/shell89.c` - `main`: argument dispatch, source loading, registration,
  running, diagnostics, exit status.
- `tool/shell89_cli.c` / `tool/shell89_cli.h` - argument parsing, bounded
  source reading, stream commands, and registration.
- `tool/shell89_lines.c` / `tool/shell89_lines.h` - line reader, literal
  matching, line-count parsing, and `grep`/`head`/`skip`.
- `tests/cli/test_cli.c` - unit tests for shared helpers.
- `tests/cli/test_lines.c` - unit and command tests for line-oriented behavior.
- `scripts/cli-check.sh` - end-to-end behavior, statuses, and stdout/stderr
  separation.
- `examples/scripts/` - twenty runnable example scripts, fixtures, expected
  outputs, and an index. See `0004-example-scripts.md`.

`examples/cli.c` is removed; `examples/embed.c` remains the embedding example.
